LLVM · #228128 · AArch64 · GlobalISel

Merged

Carry reuse across debug instructions ↗

Debug information should not change the selected carry-handling instructions.

GlobalISel checked the immediately previous instruction before reusing carry flags. An intervening debug instruction broke that adjacency test and caused extra instructions to materialize and reconstruct the carry. The merged change skips consecutive debug instructions before checking the producer, with MIR regression coverage for add/sub combinations and boundary cases.

LLVM · #234690 · RISC-V · MC / LLD

Open

Function alignment during linker relaxation ↗

Preserving minimum alignment when earlier instructions shrink at link time.

The proposed change adds an assembler-backend hook so RISC-V can emit an alignment relocation for preferred-alignment padding. This lets the linker adjust that padding during relaxation instead of leaving fixed NOPs that can shift the function entry out of alignment. The PR includes MC and LLD regression tests.

LLVM · #235458 · Clang · C++ modules

Open

Distinct names for local lambda types ↗

Preventing different local lambdas from receiving the same mangled name.

In function templates inside named modules, one mangling path omitted closure prefixes. The proposed fix preserves those prefixes without repeating the enclosing function encoding. Regression cases cover ordinary and generic lambdas, mixed static/non-static locals, and two static locals.

LLVM · #228037 · Flang · OpenMP

Open

Error recovery for cyclic Fortran modules ↗

Keeping a diagnosed module USE cycle from turning into a compiler crash.

After name resolution reports a cycle, some module names have no symbol. The proposed change guards the OpenMP checker before dereferencing those symbols and makes the semantic visitor honor a failed entry. Skipping both child traversal and the matching leave operation keeps scope and construct stacks balanced. A regression test exercises the OpenMP path.

ClickHouse · #127725 · Parsing · Dynamic

Open

Preserving NULL values in Dynamic columns ↗

Keeping null values from becoming strings or numeric zero during parsing.

The proposed change handles transitions from expression parsing in VALUES and recognizes format-specific null markers before type inference. It also preserves TSV escaping until deserialization. The scope includes VALUES, CSV, and TSV, including configurations where input_format_null_as_default is disabled.

ClickHouse · #124910 · Storage · Iceberg

Open

Valid metadata for unsorted Iceberg tables ↗

Making empty sort-order metadata interoperable with other Iceberg implementations.

ORDER BY tuple() has an AST but produces no sorting fields. The proposed change determines the sort-order ID from those fields, using the reserved unsorted ID 0 for an empty order. Regression tests cover both REST-catalog table creation and generated IcebergS3 metadata subsequently registered in a catalog.
